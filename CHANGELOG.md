## 0.0.4

* **Feature:** Enforced Material 3 card design solutions with built-in `variant` support (`elevated`, `filled`, `outlined`, `none`).
* **Feature:** Automatic `EzCircleAvatar` generation when `avatar` is omitted, resolving initials and deterministic color from `name`.
* **Feature:** 100% drop-in compatibility with standard Flutter `ListTile` via `leading`, `trailing`, `title`, `dense`, and `enabled` properties.
* **Feature:** Added screen-reader accessibility with automated `Semantics` label calculation.
* **Refactor:** Aligned documentation with Effective Dart standards and structured logic using `_EzContactCardHelper`.
* **Test:** Expanded widget test suite covering all variants, aliases, dense mode, disabled state, and semantics.
* **Example:** Updated demo app showcasing zero-config usage, Material 3 variants, drop-in compatibility, and states.
